# Настройка VPN (AWG + Xray) — кратко

Плейбук «с нуля до проверенного туннеля»: выбор протокола (AmneziaWG по UDP или
Xray VLESS+REALITY/XHTTP по TCP), подготовка VPS, сервер, клиенты по одному на
устройство, роутинг (Linux — `linux-routing`, OpenWrt — `podkop-openwrt-guide`,
`amneziawg-openwrt-guide`), проверка и траблшутинг по симптомам — `checklist.md`.

Обфускация не спасает от блокировки по IP и не даёт анонимности.
