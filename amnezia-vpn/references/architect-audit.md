# Аудит architect.vai-rice.space (AWG/Xray Architect), 2026-10-15

Сайт — SPA-генератор/валидатор конфигов AmneziaWG и Xray (разделы `/amneziawg`,
`/xray`, `/faq`, `/simulator`, `/mergekeys`, `/about`), плюс FAQ (~80 вопросов),
матрица клиентов и правила валидации. Контент извлечён из JS-бандла (сайт без SSR).
Сверено с `amnezia-vpn/amneziawg-go` README (теги v3.1.*) и release notes / исходниками `XTLS/Xray-core` (последний релиз v26.10.10).

## Что полезно (перенесено в скиллы)

- Разделение параметров AWG на shared / sender / local и что обязано совпадать (H1–H4, S1–S4, HeaderProtectionKey, RandomTrailers).
- Порог S1–S4 ≥ 12 при HeaderProtectionKey (подтверждено README upstream).
- Правило `S1 + 56 ≠ S2`, запрет H в зоне 1–4, непересекающиеся H-диапазоны.
- Совместимость тегов I1–I5 по движкам: `<c>` только kmod, `<d>/<ds>/<dz>` только go; незнакомый тег отвергает весь пакет.
- Лимит netlink для цепочки I1–I5 в модуле ядра (`Message too long`).
- Ограничения клиентов: H ≤ 2147483647 у wg-easy и AmneziaWG Windows < 2.0.2; WireSock игнорирует I1–I5; mihomo нужен `version: 3` для AWG 3.x.
- Xray: `-udp443` только на клиенте; REALITY только поверх RAW/XHTTP/gRPC; требования к shortIds/xver/fingerprint; согласование `target` и `serverNames`; логика `mode: auto` в XHTTP.
- Траблшутинг по `Invalid argument` / долгому подключению / периодическим обрывам.
